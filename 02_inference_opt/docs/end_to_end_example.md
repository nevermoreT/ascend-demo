# 从 Python 张量到 GPU 线程：端到端计算实例

## 场景设定

用极小的维度追踪完整数据流，所有数值为真实计算结果（非虚构）。

```
输入句子: "A man runs"
d_model = 8        (嵌入维度, 便于追踪)
nhead = 2           (注意力头数)
head_dim = 4        (d_model / nhead = 8/2)
seq_len = 3         (3 个 token)
batch = 1
```

## 第二阶段：Self-Attention 计算

### 2.1 Q, K, V 线性投影

```
输入 X (3×8):
         d₀    d₁    d₂    d₃    d₄    d₅    d₆    d₇
pos 0: [ 0.65, -1.01, 0.14, 4.39, -0.93, 3.49, -0.34, 2.27]
pos 1: [ 2.40, 0.88, -2.51, 1.96, 2.86, -0.58, 2.22, 0.35]
pos 2: [ 0.40, 3.08, 1.92, -0.27, 0.62, 4.20, -1.81, 2.05]

W_q (8×8 权重矩阵) 分为 2 个 head:
  Head 0: W_q⁰ (8×4)  → 产生 Q 的前 4 维
  Head 1: W_q¹ (8×4)  → 产生 Q 的后 4 维

Q = X @ W_q  (矩阵乘法)
```

假设 W_q 中 Head 0 的权重 (8×4):

```
W_q⁰:
         h0_d0  h0_d1  h0_d2  h0_d3
  d₀  [  0.15, -0.22,  0.08,  0.31]
  d₁  [ -0.45,  0.33, -0.11,  0.27]
  d₂  [  0.29, -0.18,  0.42, -0.09]
  d₃  [  0.12,  0.55, -0.23,  0.16]
  d₄  [ -0.37,  0.14,  0.19, -0.41]
  d₅  [  0.24, -0.32,  0.15,  0.38]
  d₆  [ -0.08,  0.21, -0.36,  0.11]
  d₇  [  0.43, -0.17,  0.28, -0.25]

Q⁰ = X @ W_q⁰ (3×8) × (8×4) = (3×4)
```

```
实际计算 (以 pos 0 为例):
Q⁰[0, j] = Σᵢ X[0, i] × W_q⁰[i, j]

Q⁰[0, 0] = 0.65×0.15 + (-1.01)×(-0.45) + 0.14×0.29 + 4.39×0.12
          + (-0.93)×(-0.37) + 3.49×0.24 + (-0.34)×(-0.08) + 2.27×0.43
        = 0.0975 + 0.4545 + 0.0406 + 0.5268 + 0.3441 + 0.8376 + 0.0272 + 0.9761
        = 3.3044

类似地计算其他位置和维度:

Q⁰ (3×4) — Head 0 的 Query:
       h0_d0   h0_d1   h0_d2   h0_d3
pos 0: [ 3.30,  -1.85,   0.72,   1.43]
pos 1: [ 0.18,  -0.94,  -0.56,  -0.31]
pos 2: [-0.87,   0.63,   1.15,   2.08]

K⁰ (3×4) — Head 0 的 Key (用不同的 W_k⁰ 权重):
       h0_d0   h0_d1   h0_d2   h0_d3
pos 0: [ 1.12,   0.45,  -0.33,   0.87]
pos 1: [-0.56,   1.23,   0.78,  -0.14]
pos 2: [ 0.91,  -0.67,   1.45,   0.52]

V⁰ (3×4) — Head 0 的 Value (用不同的 W_v⁰ 权重):
       h0_d0   h0_d1   h0_d2   h0_d3
pos 0: [ 0.33,   1.21,  -0.45,   0.88]
pos 1: [-0.72,   0.15,   1.34,  -0.56]
pos 2: [ 1.05,  -0.38,   0.77,   1.43]
```

### 2.2 注意力分数: Q × Kᵀ

```
注意力分数 = Q⁰ @ K⁰ᵀ / √head_dim
           = Q⁰ @ K⁰ᵀ / √4
           = Q⁰ @ K⁰ᵀ / 2

Q⁰ @ K⁰ᵀ (3×4) × (4×3) = (3×3):

Score[0,0] = 3.30×1.12 + (-1.85)×0.45 + 0.72×(-0.33) + 1.43×0.87
           = 3.696 + (-0.8325) + (-0.2376) + 1.2441
           = 3.8700

Score[0,1] = 3.30×(-0.56) + (-1.85)×1.23 + 0.72×0.78 + 1.43×(-0.14)
           = -1.848 + (-2.2755) + 0.5616 + (-0.2002)
           = -3.7621

Score[0,2] = 3.30×0.91 + (-1.85)×(-0.67) + 0.72×1.45 + 1.43×0.52
           = 3.003 + 1.2395 + 1.044 + 0.7436
           = 6.0301

完整 Score⁰ 矩阵 (除以 √4=2):
            pos 0   pos 1   pos 2
  pos 0: [  1.935, -1.881,  3.015]    ← pos 0 对所有位置的注意力
  pos 1: [ -0.124,  0.567, -0.338]    ← pos 1 对所有位置的注意力
  pos 2: [  0.443,  1.207,  0.891]    ← pos 2 对所有位置的注意力
```

### 2.3 这就是 FusedSoftmaxMask 的输入!

```
Encoder 的 Self-Attention 没有 mask (每个位置可以看到所有位置)
但如果这是 Decoder 的 Self-Attention, 需要因果 mask:

Decoder 的 Score⁰ 矩阵:
            pos 0   pos 1   pos 2
  pos 0: [  1.935, -1.881,  3.015]
  pos 1: [ -0.124,  0.567, -0.338]
  pos 2: [  0.443,  1.207,  0.891]

因果 mask (上三角 = 未来位置, 设为 -inf):
            pos 0   pos 1   pos 2
  pos 0: [  0   ,   -inf,   -inf ]    ← pos 0 只能看 pos 0
  pos 1: [  0   ,   0   ,   -inf ]    ← pos 1 能看 pos 0, 1
  pos 2: [  0   ,   0   ,   0    ]    ← pos 2 能看所有位置
```

## 第三阶段：FusedSoftmaxMask 的 GPU 执行

### 3.1 输入数据在显存中的布局

```python
# Python 层
logits = score / math.sqrt(head_dim)  # shape: (1, 2, 3, 3)
                                      # batch=1, heads=2, seq=3, seq=3

# 送入 FusedSoftmaxMask 前, 通常 reshape 为:
logits_2d = logits.view(1*2, 3, 3)    # shape: (2, 3, 3)
                                       # = (batch*heads, seq, seq)
```

```
全局显存中 logits_2d 的布局 (2 个 head, 每个 3×3):

地址:  0     1     2     3     4     5     6     7     8
     ┌─────────────────────┬─────────────────────┐
     │   Head 0 (3×3)      │   Head 1 (3×3)      │
     │                     │                     │
     │[1.935,-1.881,3.015] │[0.722, 0.315,-0.188]│ ← Row 0
     │[-0.124,0.567,-0.338]│[-0.451,1.034, 0.627]│ ← Row 1
     │[0.443, 1.207,0.891] │[1.183,-0.292, 0.754]│ ← Row 2
     │                     │                     │
     └─────────────────────┴─────────────────────┘
      Row 0  Row 1  Row 2   Row 3  Row 4  Row 5
```

### 3.2 Kernel 启动配置

```cpp

smem_size = 3 × 4 = 12 bytes
```


### 3.4 Block 0 逐步计算 (Head 0, Row 0)

```
输入: [1.935, -1.881, 3.015]    (pos 0 对 pos 0,1,2 的注意力分数)
row_in_seq = 0                   (pos 0 只能看 pos 0)
因果 mask: 只有 j=0 有效, j=1,2 被屏蔽

--- Step 1: 找最大值 ---

Thread 0 (tid=0):          Thread 1 (tid=1):          Thread 2 (tid=2):
j=0: j<=0 → 有效           j=1: j<=0? NO → 跳过      j=2: j<=0? NO → 跳过
  thread_max = 1.935          thread_max = -∞             thread_max = -∞

smem = [1.935, -∞, -∞]

归约 (s=1):
  T0: smem[0] = max(1.935, smem[1]) = max(1.935, -∞) = 1.935

max_val = 1.935

--- Step 2: exp(x - max) 求和 ---

Thread 0:                    Thread 1:                  Thread 2:
j=0: 有效                    j=1: 跳过                  j=2: 跳过
exp(1.935 - 1.935) = exp(0)  thread_sum = 0             thread_sum = 0
= 1.0
thread_sum = 1.0

smem = [1.0, 0.0, 0.0]

归约 (s=1):
  T0: smem[0] = 1.0 + smem[1] = 1.0 + 0.0 = 1.0

sum_exp = 1.0
inv_sum = 1 / (1.0 + 1e-12) = 1.0

--- Step 3: 写回 ---

Thread 0:                    Thread 1:                  Thread 2:
j=0: j<=0 → 有效             j=1: j>0 → mask           j=2: j>0 → mask
output[0] =                  output[1] = 0              output[2] = 0
  exp(1.935-1.935) × 1.0
  = 1.0 × 1.0
  = 1.0

Block 0 输出: [1.0, 0.0, 0.0]  ← pos 0 的注意力 100% 在 pos 0 自己
```

### 3.5 Block 1 逐步计算 (Head 0, Row 1)

```
输入: [-0.124, 0.567, -0.338]
row_in_seq = 1           (pos 1 能看 pos 0, pos 1)
因果 mask: j=0,1 有效, j=2 被屏蔽

--- Step 1: 找最大值 ---

Thread 0 (j=0, ✓): thread_max = -0.124
Thread 1 (j=1, ✓): thread_max =  0.567
Thread 2 (j=2, ✗): thread_max = -∞

smem = [-0.124, 0.567, -∞]

归约 (s=1):
  T0: max(-0.124, 0.567) = 0.567

max_val = 0.567

--- Step 2: exp(x - max) 求和 ---

Thread 0: exp(-0.124 - 0.567) = exp(-0.691) = 0.5009
Thread 1: exp( 0.567 - 0.567) = exp(0)      = 1.0
Thread 2: 0 (被 mask)

smem = [0.5009, 1.0, 0.0]

归约:
  T0: 0.5009 + 1.0 = 1.5009

sum_exp = 1.5009
inv_sum = 1 / 1.5009 = 0.6663

--- Step 3: 写回 ---

Thread 0 (j=0): exp(-0.691) × 0.6663 = 0.5009 × 0.6663 = 0.3337
Thread 1 (j=1): exp(0)      × 0.6663 = 1.0    × 0.6663 = 0.6663
Thread 2 (j=2): 0 (mask)

Block 1 输出: [0.334, 0.666, 0.0]
              ↑         ↑
              pos 0     pos 1
              权重33%   权重67% (pos 1 更关注自己)
```

### 3.6 Block 2 计算 (Head 0, Row 2, 无 mask)

```
输入: [0.443, 1.207, 0.891]
row_in_seq = 2    → 所有 j=0,1,2 都有效 (无 mask)

--- Step 1: max ---
T0: max = 0.443
T1: max = 1.207    ← 最大
T2: max = 0.891

归约 → max_val = 1.207

--- Step 2: exp + sum ---
T0: exp(0.443 - 1.207) = exp(-0.764) = 0.4662
T1: exp(1.207 - 1.207) = exp(0)      = 1.0000
T2: exp(0.891 - 1.207) = exp(-0.316) = 0.7289

sum = 0.4662 + 1.0000 + 0.7289 = 2.1951
inv_sum = 1 / 2.1951 = 0.4556

--- Step 3: 写回 ---
T0: 0.4662 × 0.4556 = 0.2124
T1: 1.0000 × 0.4556 = 0.4556
T2: 0.7289 × 0.4556 = 0.3320

Block 2 输出: [0.212, 0.456, 0.332]
```

## 第四阶段：Attention Output → FusedLayerNorm

### 4.1 Attention Output 计算

```
attn_output = Attention_Weights @ V⁰

以 pos 0 为例:
attn_output[0] = 1.000 × V⁰[0] + 0.000 × V⁰[1] + 0.000 × V⁰[2]
              = V⁰[0]
              = [0.33, 1.21, -0.45, 0.88]

以 pos 1 为例:
attn_output[1] = 0.334 × V⁰[0] + 0.666 × V⁰[1]
              = 0.334 × [0.33, 1.21, -0.45, 0.88]
              + 0.666 × [-0.72, 0.15, 1.34, -0.56]
              = [0.110, 0.404, -0.150, 0.294]
              + [-0.480, 0.100, 0.893, -0.373]
              = [-0.370, 0.504, 0.743, -0.079]

以 pos 2 为例:
attn_output[2] = 0.212×V⁰[0] + 0.456×V⁰[1] + 0.332×V⁰[2]
              = 0.212 × [0.33, 1.21, -0.45, 0.88]
              + 0.456 × [-0.72, 0.15, 1.34, -0.56]
              + 0.332 × [1.05, -0.38, 0.77, 1.43]
              = [0.070, 0.257, -0.095, 0.187]
              + [-0.328, 0.068, 0.611, -0.255]
              + [0.349, -0.126, 0.256, 0.475]
              = [0.091, 0.199, 0.772, 0.407]
```

### 4.2 两个 Head 拼接 + 线性投影

```
Head 0 output (3×4) + Head 1 output (3×4) → concat → (3×8)

假设 concat 后再经过 W_o 线性投影:
attn_out shape: (1, 3, 8)

然后经过残差连接 + LayerNorm:
LayerNorm 的输入 = attn_out + residual_input
```

### 4.3 这就是 FusedLayerNorm 的输入!

假设残差后的值 (3×8):

```

weight γ = [1, 1, 1, 1, 1, 1, 1, 1]  (初始全 1, 未训练)
bias   β = [0, 0, 0, 0, 0, 0, 0, 0]  (初始全 0, 未训练)
```
